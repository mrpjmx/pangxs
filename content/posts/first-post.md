## 👋 欢迎来到自留地

这是我用 **飞牛系统(fnOS)** + **Hugo** + **PaperMod 主题** 搭起来的个人站。

### 🎯 这个站做什么

- 记录飞牛系统折腾过程
- 分享摩旅老登抖音运营心得
- 嘉祥外国语信息化工作笔记
- 偶尔的生活随笔

### 🛠️ 技术栈

| 组件 | 版本 |
|---|---|
| 飞牛 fnOS | Debian 12 bookworm |
| Hugo | v0.165.0 extended |
| PaperMod | v8.0 (commit d376885) |
| GitHub | mrpjmx/fnhugo |
| 托管 | Cloudflare Pages |
| 域名 | fn.028317.xyz |

### 📦 仓库结构

```
fnhugo/
├── content/           # 内容(博客)
│   ├── posts/        # 文章
│   ├── about/        # 关于页
│   └── archives/     # 归档页
├── static/           # 静态资源
├── themes/
│   └── PaperMod/     # PaperMod 子模块
└── hugo.toml         # 站点配置
```
